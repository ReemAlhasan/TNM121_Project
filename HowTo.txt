

____________________________START SERVER___________________________________

    1. Make sure everything below is done going from last to first.
    2. Navigate to server directory and write the following in terminal to start the server. 
		command: node app.js
	3. Open a html file in a browser (e.g., Firefox) and you are ready to go!

______________________________LOAD DATA_____________________________________

        OBS: this step is done once to insert the data in to your local mongodb database

	1. Navigate via terminal to server directory and ensure all external modules are 
		installed accorded to "package.json" by running the 
		command:npm install.
		(A package-lock.json and node modules should show upp now)
	2. Go to the mongo leaf in left command pannel and ensure the mongo server is up and running and conected. 
		if not -> MongoDB Connection String: mongodb://127.0.0.1:27017
		(should be conected and thre defult directorys show)
	3. The "/server/mongodb/mongodb-setup.js" needs to be executed once to inport the documents into 
		MongoDB Database Collection. Do that via the following 
		command: node mongodb/mongodb-setup.js
    4. OBS once you have conected the local mongodb database you can delite the files   
        "Server/data-import/package-lock.json" and Server/data-import/mongodb-modules"
        before commiting and pushing your chanches to GIT repository
